# Demo senaryoları

Aşağıdaki örnekler sentetik senaryo tarifleridir; uygulamada otomatik oluşturuldukları ayrıca doğrulanmalıdır.

| Senaryo | Örnek | Beklenen gözlem |
|---|---|---|
| Görev atama | Depo sayım planı — Operasyon Ekibi | Sorumlu ve termin görünür |
| Gecikme | Sevkiyat kontrolü — termin geçmiş | Gecikme görünür |
| Engelli iş | Entegrasyon testi — dış bağımlılık | Engel nedeni izlenebilir |
| Ekip koordinasyonu | Rapor doğrulama — iki ekip | Ortak sorumluluk açıklanabilir |
| Tamamlama | Kontrol listesi bitmiş görev | Tamamlama durumu gösterilir |

Demo anlatımı: problem → görev → sorumlu → durum → termin → engel → sonuç.
